<p align="center"><b>Game profiles for UNIMOD</b></p>

UNIMOD downloads the profiles in this repository automatically, so new and improved games show up in its
supported-games list without installing anything.

- The game profiles are the `.json` files in [`/profiles`](profiles).
- A profile works with the game version it was made on.
- Found a profile that doesn't work? Open an Issue with the game name and its version.
